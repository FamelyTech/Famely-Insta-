environment variables
-open '.env' at the top level of the project
***

project setup
-create a superuser with manage.py
-runserver through manage.py and open the browser to the admin
-create a test user
-create a grafana account and make the dashboards

proxy
-go to webshare.io and create an account
-locate 'API' at the bottom of the left side of the page, click on it and create an API key
-add the API key to the environment variables as 'WEBSHARE_API_KEY'
-locate 'PROXY LIST' near the top of the options on the left side of the page, and open it
-pick an available proxy and port combination [proxy address(xxx.xxx.xxx.xx)]:[port(xxxx)], and save it

hosting
find a tutorial for hosting a django application and do that

using the application
1) with the test user or the super user created in the setup, log in to the landing page
2) after you've been redirected to the 'create jalodei user' page,
-enter a working instagram username and password combination
-for the proxy field, enter the proxy port combination from before with ':' between the proxy address and the port
3) after you've been logged in, you should see a page with a list of loaded users (the first time you access this page it should only show the active user)
-click on a user name to load the account page for that user
-or enter a different user name in the account textbox at the top of the page and click on the eyes to load the page
4) from the account page, you should see a list of media for the user
-click on the 'media chart' icon to load a dashboard for the account
-click on a media id to load the analysis of that media
-or enter the media id in the media textbox to to load the analysis
5) from the media analysis page, you should see some analysis of the post - some basic metrics, summary, facial analysis, and comment analysis
-click on the 'media chart' icon to load a dashboard for the media
-click on the 'facial analysis' icon to load a dashboard for the emotions on the top-left face in the image
